# no-stop-web-dev

One website a day, every day. A public log of small builds — each one designed, shipped and documented.

## Open the index

`index.html` is the hub: it lists every build as a row you can click through to the real page.

- **Index / hub:** [index.html](index.html)
- **Build 01:** [day-01-landing/](day-01-landing/)

Serve the whole repo locally so the links between pages resolve:

```bash
python -m http.server 8123
# then open http://127.0.0.1:8123/
```

Opening `index.html` directly from the file system also works, since every link is relative.
